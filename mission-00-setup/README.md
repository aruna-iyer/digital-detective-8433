### What is a repository?

A repository is a project folder tracked by Git. Git records changes so I can save work as commits and publish it to GitHub.

### Why organize the project by mission?

Separate folders keep each mission’s notes, code, and evidence together. This makes the project easier to review and lets me commit each mission separately.

## 3. Commands / tools used

- `python3 --version` — checked the installed Python 3 version.
- `git --version` — checked the installed Git version.
- `mkdir` — created folders.
- `touch` — created empty files.
- `git init` — initialized Git tracking in the project folder.
- `git add` — selected files for a commit.
- `git commit` — saved a project snapshot in Git.
- `git remote add origin` — connected the local repository to GitHub.
- `git push` — uploaded the commit to GitHub.
- VS Code — created and edited the README files.

## 4. My understanding

The local project folder contains the assignment files on my computer. Git tracks changes in that folder, and GitHub hosts an online copy of the repository. Organizing work into mission folders helps me find each mission’s work and commit it separately.
