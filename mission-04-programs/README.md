## 2. Work completed

### Compiler and interpreter comparison

| Point | Compiler | Interpreter |
|---|---|---|
| When translation / execution happens | Translates the program before it runs. | Reads and carries out instructions while the program runs. |
| Typical output | Often creates another form of the program, such as machine code. | Usually runs instructions without creating a separate executable file. |
| One example | A C compiler | The Python interpreter |
| One advantage | The translated program can run quickly after compilation. | It is convenient to run a program while developing and checking it. |

A compiler translates a program before running it, often producing a separate output file. An interpreter reads and carries out program instructions while the program is running. Python programs are commonly run using an interpreter. Some language implementations combine both approaches.

## 4. My understanding
