# Mission 1 — Know your computer

## 1. Task / objective

Explain how a computer uses input, processing, output, and storage (IPOS). Identify hardware, software, and computer-based systems.

## 2. Work completed

I traced the activity of downloading a Python textbook using Google Chrome and saving it in a folder in Finder.

### IPOS example: saving a Python textbook

| Stage | What happens in my example? | Hardware or component |
|---|---|---|
| Input | I searched for the Python textbook in Chrome and chose to download it. I selected where to save the file. | Keyboard, trackpad, and internet connection |
| Processing | The Mac received the download data and Chrome saved it as a file. | CPU and memory |
| Output | Chrome showed the download, and Finder let me see the saved textbook in its folder. | Screen |
| Storage | The downloaded textbook file was stored in a folder on my Mac, so I can open it later in Finder. | SSD (internal storage) |

The keyboard and trackpad let me search and choose the download. The CPU and memory helped the computer and Chrome handle the download. The screen showed what was happening. The SSD kept the downloaded file after the download finished.
